# Design prototype

Static, script-free mock of the redesigned observatory page. **Not a build artefact and not
published data**: the figures are real values copied from `docs/index.html` (built 2026-09-04)
as an illustrative subset; long manifest strings are abridged in place with a note.

Open `index.html` directly in a browser. The specification it demonstrates lives in
[`../UI_REDESIGN_SPEC.md`](../UI_REDESIGN_SPEC.md). Verification screenshots are in
`.playwright-mcp/design-prototype-*.png` (desktop first screenful, occupations section,
full page, mobile).
